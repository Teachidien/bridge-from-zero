# Panduan & Pusat Pengaturan Warna: Bridge From Zero

Dokumen ini berisi panduan dan lokasi pengaturan terpusat seluruh warna di aplikasi game **Bridge From Zero**.

---

## 📍 Lokasi File Pengaturan Warna Utama
Untuk mengubah warna aplikasi, Anda **hanya perlu membuka file kode ini**:
👉 **[src/theme/colors.ts](file:///e:/AIBaru/Bridge%20From%20Zero/src/theme/colors.ts)**

Semua komponen UI React dalam proyek ini mengambil referensi warna langsung dari file tersebut!

## 🛠️ Cara Mengubah Warna di Masa Depan
1. Buka file `src/theme/colors.ts`.
2. Ganti kode Hex warna yang ingin Anda ubah (misalnya mengganti `diamond: '#D97706'` menjadi warna lain).
3. Simpan file (`Ctrl + S`), dan seluruh warna di dalam game akan otomatis berubah!
